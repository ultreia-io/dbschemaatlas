# Security policy

## Supported versions

Security fixes are provided for the latest released version of `dbschemaatlas`.

## Reporting a vulnerability

Do not report vulnerabilities in a public issue. Use the repository's
**Security → Advisories → Report a vulnerability** page:

<https://github.com/ultreia-io/dbschemaatlas/security/advisories/new>

Include the affected version, impact, reproduction details, and any suggested
mitigation. Please do not include real credentials or private database data.
